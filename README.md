# api_final

---
##Описание проекта
API проекта Yatube позволяет:
1. Регистрироваться новым пользователям
2. Успешно входить на платформу уже существующим пользователям
3. Создавать/редактировать/удалять свои посты
4. Читать чужие посты
5. Подписываться на авторов других постов

---
##Установка на свое устройство
Клонировать репозиторий и перейти в него в командной строке:

```
git@github.com:Katrin7828/api-final-yatube.git
```

```
cd api-final-yatube
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv env
```

```
source env/bin/activate
```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python3 manage.py migrate
```

Запустить проект:

```
python3 manage.py runserver
```

##Пример запроса
Создание нового поста авторизованным пользователем
   ```
{
    "text": "Мой новый пост",
    "group": 1
}
```

Ответ
```
{
    "id": 1,
    "text": "Мой первый пост",
    "author": "<имя пользователя>",
    "image": null,
    "group": 1,
    "pub_date": "2026-09-09T08:47:10.045572Z"
}
```
