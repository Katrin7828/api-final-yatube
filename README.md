## Описание проекта:
<a id=1></a>
API проекта Yatube позволяет:
+ Регистрироваться новым пользователям
+ Успешно входить на платформу уже существующим пользователям
+ Создавать/редактировать/удалять свои посты
+ Читать чужие посты
+ Подписываться на авторов других постов

---
## Установка на свое устройство <a id=2></a>

Клонировать репозиторий и перейти в него в командной строке:

```
git@github.com:Katrin7828/api-final-yatube.git
```

```
cd api-final-yatube
```

Cоздать и активировать виртуальное окружение:

```
python3 -m venv env
```

```
source env/bin/activate
```

Установить зависимости из файла requirements.txt:

```
python3 -m pip install --upgrade pip
```

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python3 manage.py migrate
```

Запустить проект:

```
python3 manage.py runserver
```

## Пример запроса <a id=3></a>
Создание нового поста авторизованным пользователем
   ```
{
    "text": "Мой новый пост",
    "group": 1
}
```

Ответ
```
{
    "id": 1,
    "text": "Мой первый пост",
    "author": "<имя пользователя>",
    "image": null,
    "group": 1,
    "pub_date": "2026-09-09T08:47:10.045572Z"
}
```
